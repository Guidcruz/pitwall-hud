# PitWall HUD

Overlays leves por cima de simuladores de corrida (começando pelo iRacing): Standings, Relative, Combustível,
Inputs, Sessão e clima, Delta, Radar e Mapa da pista.

**Site e download:** https://guiracing.app/pitwall-hud/

Este repositório publica só os instaladores e as atualizações, na aba [Releases](../../releases). O app confere cada
atualização pelo SHA-256 publicado junto (`.sha256`) antes de instalar.
